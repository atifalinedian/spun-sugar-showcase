

# Cotton Candy Vending Machine - Business Landing Page

## Hero Section
- Bold headline introducing the automatic cotton candy vending machine experience
- Eye-catching tagline about fresh, custom cotton candy on demand
- Call-to-action buttons: "Find a Machine" and "Request a Machine for Your Venue"
- Colorful, playful gradient background with pink/blue cotton candy tones

## How It Works Section
- Step-by-step visual walkthrough (3-4 steps):
  1. Choose your flavor & design
  2. Watch the automatic sugar spinning in action
  3. Machine crafts your custom cotton candy shape
  4. Enjoy your freshly made treat
- Each step with an icon and short description
- Clean card-based layout

## Candy Design Gallery
- Grid showcase of cotton candy designs: flowers, hearts, swirls, characters
- Image placeholders with colorful styled cards (ready for real photos later)
- Hover effects for visual engagement
- Section headline like "Art You Can Eat"

## Find a Machine / Locations Section
- List of current machine locations displayed as cards with venue name, address, and hours
- Sample location data (malls, amusement parks, event centers)
- Simple, scannable layout with location pin icons

## Contact / Request a Machine Form
- Form for venue owners to request a machine installation
- Fields: Name, Business Name, Email, Phone, Venue Type, Message
- Client-side validation with clear error feedback
- Success toast notification on submission (frontend only, no backend)

## Footer
- Business name and tagline
- Quick navigation links
- Social media icon placeholders
- Copyright info

## Design & Style
- Playful yet professional color palette: pinks, light blues, and whites
- Smooth scroll navigation from a sticky top navbar
- Fully responsive (mobile-friendly)
- Subtle animations on scroll for section reveals
